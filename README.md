# Зельеварня чудес

**Potion Wonders / İksir Harikaları**

Самостоятельная casual match-3 игра на Phaser 3, создаваемая на стабильной технической базе «Безумных ягодок» с полной заменой визуала, аудио, брендинга и текстов.

## Форматы
- mobile: вертикальный 9:16, ориентир 1080×1920;
- ПК: горизонтальный 16:9, ориентир 1920×1080;
- игровое поле: 8×8.

## Визуальное направление
Premium casual fantasy: уютная волшебная зельеварня в башне, стекло, золото, дерево, латунь, индиго, изумруд, фиолетовый, янтарный и бирюзовые свечения.

Постоянный фирменный элемент окружения — крупная латунно-золотая астролябия с бирюзовым свечением.

## Витринные названия
- RU: «Зельеварня чудес»
- EN: Potion Wonders
- TR: İksir Harikaları

`POTION_WONDERS`, если используется в коде, — только внутренний технический идентификатор. Репозиторий пока сохраняет имя `LAVKA_CHUDES`.

## Техническая база
Сохраняются проверенные match-3 механики, 30-уровневая data-driven кампания, жизни, монеты, бустеры, rewarded-механики, Yandex SDK adapter, cloud-save hooks, сборщик релиза и GitHub Actions.

Старые ягодные ассеты не удаляются до поэтапной замены и проверки нового production-арта.
